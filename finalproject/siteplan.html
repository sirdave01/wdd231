ByteHaven Tech Solutions Ltd - Site Plan

WDD231 Individual Project - Osigwe Uchechukwu DavidCaleb

1. Site Name:

ByteHaven Tech Solutions Ltd
“Byte” = digital/code, “Haven” = trusted place. Modern, memorable, clearly tech-focused.

2. Site Purpose

Official company website to showcase web development, custom software, and tech training services. Attract clients, display live data demos, and provide an easy contact form.

3. Scenarios

  • What kinds of websites and apps has ByteHaven built?
  • How much does a custom website cost?
  • Can ByteHaven train my team on modern web tools?
  • Where can I see your CAC certification?
  • How do I request a quote?

4. Color Scheme

Color Hex Usage
Dark Navy #0F172A Background, footer
Teal (Primary) #00D4D4 Headings, buttons, accents
Light Teal #5FE9E9 Hovers, highlights
White #FFFFFF Text, cards

5. Typography

  • Headings – Space Grotesk (500–700)
  • Body – Inter (400–600)

6. Wireframe Sketches – Home Page

Mobile-first responsive layout with hero, trust badges (incl. CAC cert), services preview, live API widgets (weather, crypto, exchange rates), recent projects, testimonials, CTA, and footer.
